================================================================================

1. DESKRIPSI & OVERVIEW PROYEK
--------------------------------------------------------------------------------
Proyek "perpustakaan-app" adalah aplikasi berbasis web yang dibangun menggunakan 
framework Laravel 11. Aplikasi ini dirancang untuk mengelola operasional 
perpustakaan perguruan tinggi / sekolah, mencakup presensi/kunjungan harian 
mahasiswa, manajemen data buku, transaksi peminjaman & pengembalian buku, 
serta manajemen pengguna.

Teknologi Utama:
- Backend & Framework : Laravel 11.x (PHP 8.2+)
- Database           : MySQL / MariaDB (Database: `perpustakaan_db`)
- Frontend / Layout  : Blade Templating + Bootstrap 5 + FontAwesome + Plus Jakarta Sans Font
- Visual Analytics   : Chart.js (Grafik kunjungan & peminjaman)
- Tema Warna Barunya : Modern Emerald Teal Slate & Indigo Accent (UI Modern Elevation)

Aplikasi menggunakan Multi-Role Access Control (RBAC) dengan 2 peran pengguna:
1. Admin      : Pengelola utama sistem perpustakaan.
2. Mahasiswa  : Pengunjung & peminjam fasilitas perpustakaan.


2. ANATOMI FITUR & MODUL UTAMA
--------------------------------------------------------------------------------
[A] MODUL AUTENTIKASI & OTORISASI
- Login Multi-Role      : Membedakan alur redirection (Admin ke `/admin/dashboard`, 
                          Mahasiswa ke `/mahasiswa/dashboard`).
- Registrasi Publik     : Pendaftaran akun baru otomatis menetapkan role default sebagai `mahasiswa`.
                          Mendukung pengisian Nama, Email, NIM/NIP, Jurusan, & No Telepon.
- Role Middleware       : Route dilindungi middleware `CheckRole` (`role:admin` & `role:mahasiswa`).

[B] PANEL ADMIN (/admin/*)
- Dashboard Admin       : 
  * Kartu statistik (Total Mahasiswa, Total Stok Buku, Buku Tersedia, Peminjaman Aktif).
  * Table realtime mahasiswa yang sedang berada di lokasi (belum check-out).
  * Grafik Presensi 7 hari terakhir & Peminjaman 6 bulan terakhir.
  * Ranking 5 Buku Paling Populer (sering dipinjam).
- Manajemen User        : CRUD data pengguna (Admin & Mahasiswa).
- Manajemen Buku        : CRUD koleksi buku + Fitur Cetak Katalog Buku.
- Manajemen Peminjaman  : Catat Peminjaman, Potong Stok, Pengembalian & Denda otomatis, 
                          serta Fitur Cetak Laporan Peminjaman.
- Manajemen Kunjungan   : Memantau presensi kehadiran mahasiswa + Fitur Cetak Laporan Kunjungan.

[C] PANEL MAHASISWA (/mahasiswa/*)
- Dashboard Mahasiswa   : Status presensi hari ini, Riwayat Peminjaman Aktif, Riwayat Kunjungan.
- Katalog Buku Online   : Jelajahi koleksi buku, pencarian judul/penulis/kategori, 
                          serta Fitur Peminjaman Buku Mandiri secara langsung.
- Presensi Check-in     : Presensi kehadiran dengan opsi Kamera Live (Webcam HTML5 direct capture) 
                          maupun unggah file foto dari galeri.
- Presensi Check-out    : Fitur menyelesaikan sesi kunjungan di hari tersebut.

4. SARAN PENGEMBANGAN FITUR SELANJUTNYA
--------------------------------------------------------------------------------
1. Notifikasi Pengingat Otomatis (WhatsApp Gateway / Email):
   - Mengirimkan pengingat H-1 sebelum tanggal pengembalian dan pemberitahuan saat buku 
     sudah mengalami keterlambatan agar denda dapat diminimalisir.
2. Kartu Anggota Digital & QR Code Scanner:
   - Generator QR Code / Barcode untuk Kartu Tanda Mahasiswa (KTM Digital) dan Buku.
   - Fitur scanner QR pada Admin untuk proses check-in dan pengembalian buku yang instan.
3. Fitur E-Book & Reader Online (Digital Library):
   - Pengunggahan file PDF e-book/modul/skripsi dengan PDF Viewer yang dilindungi wat  ermark 
     agar mahasiswa dapat membaca buku secara digital langsung dari sistem.
4. Approval Workflow Peminjaman:
   - Menambahkan status persetujuan (`diajukan`, `disetujui`, `ditolak`, `dipinjam`) sehingga 
     Admin dapat meninjau pengajuan pinjam mahasiswa sebelum buku diambil di lokasi.
5. Integration Payment Gateway (QRIS/E-Wallet):
   - Pembayaran denda keterlambatan secara cashless menggunakan QRIS / Midtrans.
6. Export Laporan Format Excel (.xlsx) & PDF Resmi:
   - Ekspor rekapitulasi bulanan/tahunan data peminjaman, keuangan denda, dan kehadiran mahasiswa.


5. REKOMENDASI TEKNOLOGI KEDEPANNYA (FUTURE TECH STACK)
--------------------------------------------------------------------------------
1. Realtime WebSockets (Laravel Reverb / Pusher):
   - Memperbarui statistik dashboard dan daftar presensi mahasiswa secara realtime 
     tanpa reload halaman saat ada presensi atau transaksi baru.
2. Progressive Web App (PWA):
   - Mengubah aplikasi menjadi PWA agar mahasiswa dapat menginstalnya di HP Android/iOS 
     serta menerima Push Notification.
3. Cloud Object Storage (Amazon S3 / Supabase Storage):
   - Memindahkan media simpanan foto presensi dan sampul buku ke cloud storage 
     untuk menghemat penyimpanan lokal server dan mempercepat loading.
4. AI Recommendation System (Collaborative Filtering / OpenAI API):
   - Memberikan rekomendasi buku bacaan yang relevan bagi mahasiswa berdasarkan 
     jurusan, minat baca, atau riwayat peminjaman terdahulu.
5. In-Memory Caching (Redis):
   - Mengimplementasikan caching layer menggunakan Redis untuk mempercepat kecepatan 
     pencarian katalog buku dalam skala ribuan data.
